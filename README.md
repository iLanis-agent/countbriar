# Countbriar 1.0 TEST
Native Java/Canvas Android 8+ Nanro labeled-room-count puzzle.

Label some tiles so all labeled tiles form one edge-connected group. Every room must have at least one label. Each digit equals the number of labeled tiles in its room. No 2x2 may be fully labeled. Labels touching across a room border must have different values. Circled given digits stay fixed. Tap other tiles to label or clear them; their digits update to the current room count. Twelve unique 4x4 room/clue boards have twelve distinct solutions.

Saved count palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java coordinate-neighbor, set/BFS and room-set oracle checks all 65536 masks per board against production bitset connectivity, counts and pairwise exclusions, proving one solution each. Fixed clues, bounds, solve, undo and replay pass. Adapter menu, settings, privacy, taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 104 recovered READMEs and recent cumulative stages/releases found no Nanro or Signpost Numbers match. Shared Roomhaven room-count/shading interaction is disclosed, but this connects labeled cells and derives changing room digits from the chosen occupancy, with cross-border unequal labels and no solid labeled 2x2; Heyawake instead isolates shade and constrains light rays crossing rooms. Rowparcel uses one size-valued number per room with row/column exclusions, not variable labeled counts and global label connectivity. Known Nanro genre, not a global invention.
